# Skinezy Studio

Локальный редактор Minecraft-скинов 64 × 64. Интерфейс сделан на React + TypeScript + Vite; данные текстуры хранятся как RGBA-буфер, пиксельные операции вынесены в отдельный модуль, 3D-просмотр использует Three.js.

## Запуск

```sh
npm install
npm start
```

Откройте `http://127.0.0.1:5173`. Production-сборка: `npm run build`. Автоматические проверки: `npm test`.

## Реализовано

- Импорт и экспорт PNG 64 × 64 с поддержкой RGBA и сохранением RGB под нулевой альфой. Декодер принимает 8-bit non-interlaced PNG типов RGB, RGBA, grayscale и indexed. Legacy 64 × 32 открывается после явного подтверждения; недостающие пиксели остаются прозрачными. Другие размеры отклоняются.
- Независимые открытые проекты с автоматическим сохранением текстур и модели в браузере, пиксельная история Undo/Redo, стандартные стартовые скины Steve/Alex и экспорт PNG.
- Карандаш, размерная шумовая кисть с повторяемым seed, ластик, связанная заливка с допуском, пипетка, прямоугольное выделение, копирование/вырезание/очистка, вставка, отражение по горизонтали/вертикали и поворот фрагмента по часовой стрелке. Рамка выделения не ограничивает рисование и заливку: инструменты работают по всей текстуре.
- Lighten и Darken плавно смешивают цвет с белым и чёрным до точного конечного значения, сохраняя альфа-канал; прозрачные пиксели игнорируются.
- Grayscale, sepia, invert, brightness, contrast, saturation, hue shift, warm/cool, colorize и posterize работают с пиксельным буфером, сохраняют альфа-канал, учитывают выделение и имеют временный предпросмотр с настройкой параметра.
- Редактор текстуры показывает UV-подсказки атласа по запросу; отдельного дублирующего Raw Texture режима нет.
- 3D-просмотр Classic/Slim с масштабированием и полноэкранным режимом; панель частей тела и слоёв можно перемещать, а выбор вида камеры находится в этой панели.
- Копирование фрагмента переносит пиксели RGBA и координаты UV. Вставка работает в другой открытый проект; между вкладками Skinezy на одном адресе используется общий буфер `localStorage`, а при разрешении браузера фрагмент дополнительно попадает в системный буфер как PNG. Есть кнопки Copy/Paste и сочетания Ctrl/Cmd+C, Ctrl/Cmd+X, Ctrl/Cmd+V.
- Горячие клавиши открытия/экспорта и Undo/Redo (включая Ctrl/Cmd+Shift+Z), боковые кнопки мыши для отмены/повтора, масштабирование колёсиком в 2D, встроенный градиент выбора цвета, история цветов и четыре темы интерфейса в настройках.

## Что ещё не завершено относительно полного ТЗ

Это рабочий редактор с базовыми инструментами, но он пока не покрывает весь объём ТЗ. В частности, отсутствуют: редактируемое/перемещаемое плавающее выделение; семантическое копирование отдельных частей тела; фильтровые цепочки и сохранение пользовательских пресетов; palette reduction, dithering, outline и selective color; сохранение пользовательских палитр и экспорт проекта с историей; настраиваемая компоновка панелей; системная пипетка рабочего стола. UV-координаты всех граней заданы отдельно, а стороны и верх головы покрыты автоматическим тестом; визуальная проверка каждой поверхности контрольным цветным скином ещё не выполнена. Classic/Slim геометрия и legacy PNG нуждаются в дополнительных контрольных сценариях.

## Проверки

`npm test` проверяет координаты рисования, заливку внутри границ UV-грани, работу буфера выделения между вкладками, перенос RGBA и прозрачности при вставке, фильтры, шум кисти, осветление/затемнение до белого/чёрного, стартовые скины, сохранение RGBA при PNG round-trip, границы UV-атласа и порядок строк при загрузке текстуры в Three.js. `npm run build` выполняет TypeScript-проверку и production-сборку.
