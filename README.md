# Skinezy Studio

Локальный редактор Minecraft-скинов 64 × 64. Интерфейс сделан на React + TypeScript + Vite; данные текстуры хранятся как RGBA-буфер, пиксельные операции вынесены в отдельный модуль, 3D-просмотр использует Three.js.

## Запуск

```sh
npm install
npm start
```

Откройте `http://127.0.0.1:5173`. Production-сборка: `npm run build`. Автоматические проверки: `npm test`.

## Реализовано

- Импорт и экспорт PNG 64 × 64 с поддержкой RGBA и сохранением RGB под нулевой альфой. Декодер принимает 8-bit non-interlaced PNG типов RGB, RGBA, grayscale и indexed. Legacy 64 × 32 открывается после явного подтверждения; недостающие пиксели остаются прозрачными. Другие размеры отклоняются.
- Независимые открытые проекты, пиксельная история Undo/Redo, индикатор несохранённых изменений, создание пустого скина и экспорт.
- Карандаш, размерная шумовая кисть с повторяемым seed, ластик, связанная заливка с допуском, пипетка, прямоугольное выделение, копирование/вырезание/очистка, вставка, отражение по горизонтали/вертикали и поворот фрагмента по часовой стрелке. Штрихи и заливка ограничиваются активным выделением.
- Lighten и Darken меняют HSV value, сохраняя оттенок, насыщенность и альфа-канал; прозрачные пиксели игнорируются.
- Grayscale, sepia, invert, brightness, contrast, saturation, hue shift, warm/cool, colorize и posterize работают с пиксельным буфером, сохраняют альфа-канал, учитывают выделение и имеют временный предпросмотр с настройкой параметра.
- Raw Texture режим показывает исходный атлас и переключаемые цветные подсказки UV-участков с координатами и размерами при наведении.
- Сравнение открытых текстур в режимах side-by-side, pixel difference и overlay с регулировкой прозрачности.
- 3D-просмотр, Classic/Slim, независимое отображение базового и внешнего слоёв, переключатели головы/туловища/каждой руки и ноги, UV-конфигурация Minecraft и переключение видов. Базовая ориентация граней (включая стороны и верх головы) проверяется координатным тестом.
- Горячие клавиши открытия/экспорта, Undo/Redo, копирования/вырезания/вставки и выбора инструментов.

## Что ещё не завершено относительно полного ТЗ

Это рабочий редактор с базовыми инструментами, но он пока не покрывает весь объём ТЗ. В частности, отсутствуют: редактируемое/перемещаемое плавающее выделение; семантическое копирование отдельных частей тела; фильтровые цепочки и сохранение пользовательских пресетов; palette reduction, dithering, outline и selective color; постоянное сохранение палитры и настроек; настраиваемая компоновка панелей; полноценное сохранение проекта в файл; системная пипетка рабочего стола. UV-координаты всех граней заданы отдельно, а стороны и верх головы покрыты автоматическим тестом; визуальная проверка каждой поверхности контрольным цветным скином ещё не выполнена. Classic/Slim геометрия и legacy PNG нуждаются в дополнительных контрольных сценариях.

## Проверки

`npm test` проверяет координаты рисования, заливку и выделение, фильтры, шум кисти, HSV-lighten/darken, сохранение RGBA при PNG round-trip, границы UV-атласа и порядок строк при загрузке текстуры в Three.js. `npm run build` выполняет TypeScript-проверку и production-сборку.
